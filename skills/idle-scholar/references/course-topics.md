# 课程主题表（无工具部署时的实时生成参考）

装了 idle-scholar 插件时，卡片由 `study_card` 工具从种子题库返回，不需要本文件。
纯 skill 部署（Codex CLI、Claude Code 等没有插件的宿主）时，按下面的主题范围实时生成卡片，
每个主题出一张即可，不要临场扩大范围。

## en 英语

- **en-vocab 词汇**：CET-4/6、雅思高频词。出「认识但说不清」的词（serendipity、ubiquitous、pragmatic、nuance、leverage 一类），给例句与词根词源。避免生僻 GRE 词。
- **en-grammar 语法**：主谓一致（neither of / the number of）、虚拟语气（suggest/would rather/if I were）、倒装（hardly/no sooner）、非谓语（stop to do vs stop doing）、时态分界（完成时 vs 过去时）。
- **en-phrases 短语**：短语动词与习语（carry out、figure out、come up with、rule out、account for、take for granted），给一个中文语境例句。

## ja 日语

- **ja-vocab 词汇**：JLPT N5-N4 高频词，优先中日假同源与多义项词（勉強、手紙、結構、遠慮、すみません），标注假名读音。
- **ja-grammar 语法**：ています的结果状态用法、は/が分工、そうだ传闻 vs ようだ推测、自他动词成对（開く/開ける）、たら vs ば。
- **ja-culture 文化**：敬语三大类、本音与建前、挨拶的意义、年号与节日常识。贴士类，不需要标准答案。

## 生成规则

1. 每卡一个知识点，5 行以内：题目（＋可选提示）→ 空行 → 答案 → 一句解析。
2. 法考涉及具体数字（期限、金额、比例）时，只用你确信的现行规定；不确定就改出概念理解题。
3. 出过的考点在本会话内不重复；类型（词汇/测验/概念/贴士）轮换。
4. 用户的会话语言是中文时优先 en/ja，是英语时优先 ja/faka。
